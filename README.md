# پنل VPN (Railway) + اسکریپت سرور

## ⚡ کانفیگ WS داخلی (پینگ فوری)
خود پنل روی Railway یک رله‌ی VLESS روی WebSocket داره (مسیر `/ws/<uuid>`، مثل X4G). کانفیگ اول لینک ساب همینه:
- همون لحظه‌ی خرید فعال می‌شه (بدون sync یک‌دقیقه‌ای و بدون ری‌استارت Xray) پس پینگ می‌ده.
- مصرف هم خودکار شمرده می‌شه، با تموم‌شدن حجم/انقضا قطع می‌شه.
- اتصال به IPهای داخلی/خصوصی بلاک شده.
- از «تنظیمات پنل» می‌شه خاموشش کرد.
- حتماً Public Domain رو برای سرویس Railway فعال کن و `DATA_DIR=/data` + Volume یادت نره.

## ۱) پنل روی Railway
متغیرها در Railway:
- `ADMIN_EMAIL`، `ADMIN_PASSWORD` (فقط اولین اجرا خوانده می‌شود)
- `DATA_DIR` = `/data` و یک Volume روی `/data`
- `SYNC_KEY` = یک رشته تصادفی بلند (برای اتصال سرورها به پنل)

## ۲) سرور VPN (Ubuntu 22.04/24.04)
1. دامنه‌ای بگیر و رکورد A آن را روی IP سرور بگذار.
2. پوشه `server-setup` را روی سرور کپی کن و اجرا کن:
   `sudo bash install-xray.sh دامنه  آدرس-Railway  SYNC_KEY`
3. در پنل، بخش «سرورها»: آدرس = دامنه، SNI = دامنه، کانفیگ اول ws 443 /ws، کانفیگ دوم grpc 443 grpc.
4. هر دقیقه کاربران فعال به Xray می‌روند و مصرف واقعی به پنل برمی‌گردد.

## ۳) L2TP (اختیاری)
اسکریپت آماده hwdsl2/setup-ipsec-vpn را نصب کن و PSK را همان PSK تنظیمات پنل بگذار.
بعد از نصب، sync.sh کاربران را در /etc/ppp/chap-secrets می‌نویسد.
مصرف L2TP و OpenVPN اندازه‌گیری نمی‌شود. OpenVPN با نام کاربری/رمز نیاز به راه‌اندازی جدا دارد.

## ضریب حجم (جدید)
حجم نهایی مشتری = حجم پلن × ضریب. مثلاً پلن ۱۰ گیگ با ضریب ۲ → توی لینک ساب (و کلاینت) ۲۰ گیگ نشون داده می‌شه و مصرف واقعی از همون ۲۰ گیگ کم می‌شه.
